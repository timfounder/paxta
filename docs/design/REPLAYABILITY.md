# REPLAYABILITY

> Owner of: why players return — within a chapter, after the story, and every
> day. Replay must fit 10–15 minute Nights and Telegram's social surface (P3),
> and must never compromise authored dread or fairness.

## 1. The replay thesis

PAXTA is **authored horror with procedural surface**: the *structure* of each
Night (curve, Directive, set-pieces) is hand-designed; the *placement* of
anomalies within it is seeded and re-rolled. So a Night is recognisable yet never
memorised — replayable without becoming rote.

- **R-REPLAY-1 Authored skeleton, procedural skin.** Curve, pacing, Directive, and
  the Night's "show" are fixed (NIGHT/HORROR_PACING); *which* anomaly appears
  *where and when* is seeded (DIFFICULTY, ANOMALY). Procedural generation never
  decides *pacing* — that would break the dread budget (HORROR_PACING R-PACE).

## 2. Replay systems (shipping order)

| System | Phase | Hook |
| --- | --- | --- |
| **Seeded re-rolls** | v1 | Every attempt of a Night differs; can't memorise. |
| **Case File completion** | v1 | Catch every variant/behaviour to complete the dossier. |
| **Daily Seed** | Phase 3 | One shared Night/day, global leaderboard, shareable. |
| **Overtime** | Phase 3 | Replay a cleared Night a tier harder for richer rewards. |
| **New Game+ ("Tenure")** | Phase 5 | Replay the story with harder anomalies + new narrative. |
| **The Long Night** | Phase 5 | Endless escalating survival mode. |

### A. Seeded re-rolls (the baseline, v1)

Each Night attempt uses a seed; anomaly kind/tier/anchor/timing are rolled within
the Night's authored knobs (DIFFICULTY §3). Re-rolled on retry and on resume
(SAVE_SYSTEM R-SAVE-3). **R-REPLAY-2** The seed varies the *contents*, never the
*curve or budget* (R-REPLAY-1).

### B. Case File completion (v1)

Completionists chase every anomaly variant and behaviour, including rare ones
(REWARD_SYSTEM R-REW-6). A pure-knowledge collectible — no grind, no RNG loot,
just *seeing everything PAXTA can be*. **R-REPLAY-3** Rare variants are *rare*, not
*gated behind repetition counts* — you find them by playing, not farming.

### C. Daily Seed (Phase 3, the Telegram hook)

One Night, one seed, everyone, every day. A weekly/daily leaderboard; a one-tap
**share** of your result via Telegram (the native viral loop, VISION §2/§7).
**R-REPLAY-4** The Daily Seed is the *same* for all players that day, so the
leaderboard measures skill on equal ground (REWARD_SYSTEM R-REW-8).

### D. Overtime (Phase 3)

Replay any cleared Night with every difficulty knob pushed a tier (DIFFICULTY §5)
for higher score and prestige. Opt-in. **R-REPLAY-5** Overtime is harder *fairly*
(more frequency/overlap/subtlety, never unfair — R-DIFF-1) and is **never sold**
(VISION R1).

### E. New Game+ "Tenure" (Phase 5) & The Long Night (Phase 5)

- **Tenure**: replay the campaign with harder anomaly behaviours and an added
  narrative layer about *what staying does to a Custodian* (STORY Ch.4 theme).
- **The Long Night**: an endless mode — survive escalating hours past 06:00 — for
  score-chasers. Authored escalation rules, not infinite noise (R-REPLAY-1).

## 3. Light branching (cheap, high-impact)

Per STORY R-NAR-5, the save already tracks catches/misses/failures. Use it:

- **R-REPLAY-6 The Supervisor remembers.** Dialogue and small world details shift
  based on your history (Clean Nights, the failure tally) — a few strings, large
  perceived depth, a reason to replay differently.
- **R-REPLAY-7 No hard branches in v1.** Endings/chapters are not gated behind
  choice trees (scope, and Pillar-4 fairness). Branching is *flavour and framing*,
  not divergent content, until proven worth the cost (FUTURE_EXPANSION).

## 4. Replay must not erode horror

- **R-REPLAY-8 Familiarity is a tool, not a leak.** A recognisable Night lets the
  player *expect* dread (then subvert it via re-rolls); it must never let them
  *defuse* it by rote (R-REPLAY-1/2).
- **R-REPLAY-9 No replay mode trades atmosphere for grind.** Every replay system
  is short-session, composure-rewarding (REWARD_SYSTEM R-REW-2), and atmosphere-
  first. If a mode would make PAXTA a number-go-up grinder, it is cut.
- **R-REPLAY-10 Respect the player's time.** Replay incentives are invitations
  (a new Daily, a missing Case File), never guilt-loops or streak punishments
  (VISION §8 caution).

## 5. Why each audience returns

| Player | Returns for |
| --- | --- |
| Story-seeker | The next chapter; the Supervisor remembering them (R-REPLAY-6). |
| Completionist | Finishing the Case Files (R-REPLAY-3). |
| Competitor | The Daily Seed leaderboard (R-REPLAY-4). |
| Challenger | Overtime / The Long Night (R-REPLAY-5). |
| Atmosphere-seeker | A short, reliable hit of dread that's never the same twice. |

## 6. Replay design checklist

1. Does it keep the authored curve/budget intact (R-REPLAY-1/2)?
2. Is it short-session and composure-rewarding (R-REPLAY-9)?
3. Is it an invitation, not a guilt-loop (R-REPLAY-10)?
4. If competitive: equal seeds for all (R-REPLAY-4)?
5. If a difficulty mode: fair-harder and unsold (R-REPLAY-5)?
